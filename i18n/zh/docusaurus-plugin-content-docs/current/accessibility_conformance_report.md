# 无障碍合规性报告

本报告说明 DHTMLX Spreadsheet 对主要无障碍标准的符合情况，采用 **VPAT® 2.5（国际版）** 的结构。如需了解无障碍功能的任务导向概述及其配置方法，请参阅[无障碍](accessibility.md)指南。

**产品名称/版本：** DHTMLX Spreadsheet v6.0.4

**报告日期：** 2026 年 10 月

**产品描述：** DHTMLX Spreadsheet 是用于 Web 应用程序的 JavaScript 电子表格组件。其界面由菜单栏、工具栏、公式栏、带行列标题的单元格网格以及工作表标签组成。其功能包括公式、单元格格式设置、合并单元格、冻结行和列、排序、筛选、搜索、数据验证、单元格链接以及 Excel 导入和导出。该组件嵌入在宿主 Web 应用程序中。

**联系方式：** [info@dhtmlx.com](mailto:info@dhtmlx.com)

## 说明 {#notes}

- 本报告评估的是 DHTMLX Spreadsheet 的**推荐无障碍配置**：即默认配置（WAI-ARIA 输出和键盘导航始终开启），并通过 `dhx.setTheme()` 或 `data-dhx-theme` 属性设置 `contrast-light` 或 `contrast-dark` 主题。备注中会指出哪些符合级别取决于此配置。设置方法请参阅[无障碍](accessibility.md)指南。
- DHTMLX Spreadsheet 是由宿主应用程序渲染的 **Web 内容**。页面级的职责（页面标题、`<html lang>`、跳过/绕过机制以及站点级导航）属于宿主应用程序，在报告中标记为*不适用*并附有说明。
- 在 WCAG 表格中，仅填写 **Web** 一项的响应。*电子文档*、*软件*、*封闭式*和*创作工具*各行均为*不适用*：本产品不是独立（非 Web）软件、封闭式功能、创作工具或电子文档。
- 作者通过单元格样式应用于单元格的颜色属于文档数据，不作为产品的一部分进行评估。

**所用评估方法：**

- 自动化测试：在 `light`、`dark`、`contrast-light` 和 `contrast-dark` 主题下使用 axe-core，并分别打开搜索栏、列表编辑器、对话框和警告框。
- 对组件源代码和样式表进行人工代码审查：包括小部件各部分的角色和 ARIA 属性、键盘处理程序和焦点区域、无障碍名称及其本地化键，以及主题颜色令牌，并计算了四种主题的对比度。
- 辅助技术测试：在 Windows 上使用 **NVDA + Firefox** 和 **JAWS + Chrome**，在 macOS 上使用 **VoiceOver + Safari** 进行人工测试。
- 浏览器覆盖设置：200% / 400% 缩放、320 CSS px 宽度下的重排，以及 WCAG 文本间距覆盖。

## 术语 {#terms}

- **支持（Supports）：** 产品的功能至少有一种方式在没有已知缺陷的情况下满足该标准，或通过等效便利措施满足该标准。
- **部分支持（Partially Supports）：** 产品的部分功能不满足该标准。
- **不支持（Does Not Support）：** 产品的大部分功能不满足该标准。
- **不适用（Not Applicable）：** 该标准与产品无关。

## WCAG 2.x 报告 {#wcag-2x-report}

DHTMLX Spreadsheet 是 Web 内容，因此下表仅填写 **Web** 一项的响应。"需要符合 AA 级的主题"属于配置依赖，而非缺陷。成功标准 4.1.1 解析（Parsing）已在 WCAG 2.2 中移除，因此不予报告。

| **1.2.3** 音频描述或媒体替代（预录制） | 不适用 | 没有预录制的多媒体。 |

| **1.3.2** 有意义的序列 | 支持 | DOM 顺序和阅读顺序与视觉顺序一致：菜单栏、工具栏、公式栏、单元格和工作表标签。单元格通过 `aria-rowindex`/`aria-colindex` 携带其在工作表中的位置，因此当行和列滚动出 DOM 时，序列仍然保持不变。 |

| **1.4.2** 音频控制 | 不适用 | 产品不产生自动播放的音频。 |
| **2.1.1** 键盘 | 支持 | 单元格上的每个命令都有对应按键，列于[快捷键列表](hotkeys.md)；`Shift`+`F10` 或 Menu 键可打开上下文菜单。`Ctrl`+`F6` 在菜单、工具栏、工作表和工作表标签之间移动焦点。各栏、其下拉菜单和弹出窗口以及列表编辑器可使用方向键、`Home`、`End`、`Enter` 和 `Esc` 操作。列宽、行高和列筛选均有上下文菜单命令。 |
| **2.1.2** 无键盘陷阱 | 支持 | 在工作表最后一个单元格上按 `Tab`、在第一个单元格上按 `Shift`+`Tab`，焦点会移出单元格，进入页面的下一部分或上一部分；`Ctrl`+`F6` 在 Spreadsheet 的各部分之间移动焦点。在列表编辑器中，`Tab` 结束编辑，`Esc` 取消编辑，使用方向键之后也是如此。`Esc` 和 `Tab` 会关闭工具栏弹出窗口，并将焦点返回到其按钮。 |
| **2.1.4** 字符键快捷键 | 支持 | 每个快捷键都使用修饰键（`Ctrl`、`Alt`、`Shift`）或非字符键（`F2`、`F6`、`F10`、`F11`、`Enter`、`Esc`、`Delete`、方向键）。在单元格上输入字符会将其录入单元格，这正是单元格的用途，不会执行命令。 |

| **2.4.2** 页面标题 | 不适用 | 页面标题由宿主应用程序负责。 |
| **2.4.3** 焦点顺序 | 支持 | 单元格在活动单元格上构成一个 Tab 停靠点，工具栏、菜单栏和工作表标签各为一个 Tab 停靠点，并按视觉顺序排列。`Tab` 在最后一个和第一个单元格处离开工作表。对话框会获取焦点，将 `Tab` 保持在对话框内，并在关闭时将焦点返回到活动单元格；菜单、上下文菜单和弹出窗口会将焦点返回到打开它们的控件；应用文本颜色或背景颜色后，焦点返回到活动单元格。活动单元格获得焦点时会滚动到可见区域。 |
| **2.4.4** 链接目的（在上下文中） | 支持 | 单元格中的链接渲染为 `<a href>` 元素，其文本为作者设置的链接文本或地址。选中单元格时，单元格文本会附加 "link"，`Alt`+`Enter` 可打开该链接。 |

| **2.5.2** 指针取消 | 支持 | 调整列和行大小以及填充柄操作在释放时生效，且一次撤销即可还原其中每一项操作。工具栏、菜单和工作表标签的命令在 `click` 时执行。 |
| **2.5.3** 标签中的名称 | 支持 | 带有可见文本的控件以该文本作为其无障碍名称：菜单项、上下文菜单命令、工作表标签和对话框按钮。图标按钮以其工具提示命名，颜色按钮以其工具提示加颜色名称命名。 |
| **2.5.4** 动作激活 | 不适用 | 没有任何功能通过设备动作或用户动作来操作。 |

| **3.2.1** 获得焦点时 | 支持 | 获得焦点从不改变上下文。点击列字母、行号或左上角单元格会选中相应的行列，并将焦点保持在活动单元格上。 |
| **3.2.2** 输入时 | 支持 | 更改值不会改变上下文。编辑单元格、从列表中选择值或在搜索栏中输入内容，都会就地更新工作表，这正是这些控件的既定用途。 |
| **3.2.6** 一致的帮助（仅 2.2） | 不适用 | 小部件不提供帮助机制；这属于页面级问题。 |
| **3.3.1** 错误识别 | 支持 | 公式错误和无效的列表值会在单元格内容中说明，例如 "Reference error. Check the cell references" 和 "Invalid value. Choose a value from the list"。编辑导致的新公式错误和无效值会通过实时区域播报，无效值的编辑器具有 `aria-invalid="true"`。 |
| **3.3.2** 标签或说明 | 支持 | 单元格编辑器名为 "Cell editor, B7"，公式栏名为 "Formula bar, B7"，其中包含被编辑单元格的地址。对话框字段带有标签，例如 "Width in pixels"，搜索栏按钮分别命名为 "Previous match"、"Next match" 和 "Close search"。 |

### 表 2：成功标准，AA 级 {#table-2-success-criteria-level-aa}

| 标准 | 符合级别 | 备注和说明 |
|---|---|---|
| **1.2.4** 字幕（直播） | 不适用 | 没有直播多媒体。 |
| **1.2.5** 音频描述（预录制） | 不适用 | 没有预录制的视频。 |
| **1.3.4** 方向 | 支持 | 内容不限于单一显示方向。 |
| **1.3.5** 识别输入目的 | 不适用 | 产品的编辑器收集的是文档数据，而非 WCAG 输入目的列表所涵盖的用户个人信息。 |
| **1.4.3** 对比度（最小值） | 支持 | `contrast-light` 和 `contrast-dark` 主题满足 AA 级：在打开搜索栏、列表编辑器、列宽对话框和警告框的情况下，两种主题中均没有产品文本的对比度低于 4.5:1。公式引用颜色在 light 和 `contrast-light` 主题中为 4.59:1 至 7.04:1，在深色主题中为 7.62:1 至 12.26:1。在默认的 light 主题中，对话框字段标签和警告文本等次要文本约为 3.95:1。要满足该标准，需要选择其中一个对比度主题，且只要采用一种受支持的方法即可满足。 |
| **1.4.4** 调整文本大小 | 支持 | 文本可放大到 200% 而不丢失内容或功能；工具栏、公式栏、工作表标签和对话框仍可正常使用。 |
| **1.4.5** 文本图像 | 支持 | 所有文本均渲染为真实文本。图标为字体字形；产品不使用位图图像。 |
| **1.4.10** 重排 | 支持 | 单元格是二维内容，该标准对其免除重排要求，可在水平和垂直方向滚动。工具栏、菜单栏和工作表标签可适应 320 CSS px 的宽度。 |
| **1.4.11** 非文本对比度 | 支持 | 单元格、公式栏和各栏控件的焦点指示器宽 2px，并使用主题颜色绘制；以下对比度数值依次对应默认 light、`contrast-light`、dark 和 `contrast-dark` 主题。活动单元格以 `--dhx-color-primary` 颜色的 2px 实线边框标记：与单元格背景的对比度约为 3.9:1、7.7:1、3.4:1 和 5.3:1。具有键盘焦点的单元格和单元格编辑器会获得同色的 2px 轮廓，对比度相同；在选定范围内约为 3.3:1、6.0:1、3.1:1 和 4.2:1。公式栏会获得 `--dhx-spreadsheet-focus-color` 颜色的 2px 轮廓：与其背景的对比度约为 3.9:1、7.7:1、5.3:1 和 6.5:1。工具栏、菜单栏和工作表标签的控件获得相同的轮廓：与栏背景的对比度约为 3.7:1、7.2:1、3.9:1 和 4.9:1。所有数值均高于 3:1 的要求。 |
| **1.4.12** 文本间距 | 支持 | 应用 WCAG 文本间距覆盖后，没有控件标签被截断；当标签增多时，工作表标签栏可滚动。 |
| **1.4.13** 悬停或焦点触发的内容 | 支持 | 工具栏工具提示在悬停时保持显示，并可通过 `Esc` 关闭，且无需移动指针或焦点。无效值工具提示用于报告输入错误，在单元格处于活动状态时保持显示，并可通过 `Esc` 移除。 |
| **2.4.5** 多种方式 | 不适用 | 适用于在一组网页中定位页面；对于单个嵌入式组件不在范围内（属于宿主应用程序的问题）。 |
| **2.4.6** 标题和标签 | 支持 | 主要部分的无障碍名称来自本地化文本："Spreadsheet"（网格）、"Formatting"（工具栏）、"Borders"、"Search" 和 "Link"（分别为边框弹出窗口、搜索栏和链接弹出窗口的工具栏）、"Main"（菜单栏）、"Cell" 和 "Sheet"（分别为单元格和工作表标签的上下文菜单）、"Sheets"（工作表标签栏）、"Formula bar, B7"（公式栏）和 "Cell editor, B7"（单元格编辑器）。全选角落单元格命名为 "Select all"，搜索栏命名为 "Search"，其按钮分别命名为 "Previous match"、"Next match" 和 "Close search"，添加工作表的按钮命名为 "Add sheet"，其他对话框以其标题命名。 |
| **2.4.7** 焦点可见 | 支持 | 键盘焦点位置始终可见。活动单元格始终带有 2px 实线边框，获得焦点的单元格或单元格编辑器带有 2px 轮廓，二者均使用主题的主色。公式栏以及工具栏、菜单栏、工作表标签、边框弹出窗口、链接弹出窗口和搜索栏的控件会显示 `--dhx-spreadsheet-focus-color` 颜色的 2px 焦点环。在调色板、边框样式列表、工具栏和菜单栏的下拉菜单以及上下文菜单中，获得焦点的项带有 1px 虚线轮廓。在列表编辑器中，获得焦点的项以背景色高亮显示。焦点指示器在每个内置主题中均会显示。 |
| **2.4.11** 焦点不被遮挡（最小）（仅 2.2） | 支持 | 活动单元格会滚动到冻结行和列旁边的可见区域，因此不会被遗留在冻结区域之后。 |
| **2.5.7** 拖动动作（仅 2.2） | 支持 | 范围选择可使用 `Shift`+方向键和 `Ctrl`+`Space`/`Shift`+`Space`。列宽和行高通过上下文菜单中的*列宽*和*行高*命令设置，并支持撤销。隐藏的行和列可通过 `Ctrl`+`Shift`+`9`/`0` 以及*显示行*/*显示列*命令显示。填充单元格可通过 [`groupFill`](api/spreadsheet_groupfill_event.md) 事件实现，该事件可绑定到上下文菜单命令。 |
| **2.5.8** 目标尺寸（最小）（仅 2.2） | 部分支持 | 填充柄为 12 x 12 CSS px。列和行的调整手柄有等效的控件，即*列宽*和*行高*命令。全选角落单元格是 40 x 32 CSS px 的角落标题单元格，工具栏和菜单控件大于 24 x 24 CSS px。 |
