# Поиск данных {#searching-for-data}

Чтобы открыть панель поиска, воспользуйтесь одним из двух способов:

- Установите фокус на любую ячейку и нажмите **Ctrl (Cmd) + F**
- Или перейдите в меню: *Data* -> *Search*

![DHTMLX Spreadsheet search bar with a text input for finding data](/img/search_data.png)

Введите в панели поиска текст, который нужно найти. Первая ячейка с этим текстом подсвечивается и прокручивается в область видимости, а счётчик показывает количество совпадений. Чтобы переходить между совпадениями, нажимайте кнопки со стрелками в панели поиска.

Результаты поиска обновляются после редактирования ячеек и после открытия другого листа. Программы чтения с экрана озвучивают количество совпадений и адрес первого совпадения после того, как вы перестанете вводить текст, например "Results: 5. 1 of 5, B2" или "No results". При переходе к другому совпадению они озвучивают его позицию и адрес, например "2 of 5, B7".

Чтобы закрыть панель поиска, нажмите **Esc** или кнопку закрытия. Фокус вернётся на активную ячейку.

Для поиска данных с помощью API используйте метод [`search()`](api/spreadsheet_search_method.md).
