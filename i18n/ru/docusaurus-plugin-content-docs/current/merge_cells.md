# Объединение ячеек {#merging-cells}

## Объединить ячейки {#merge-cells}

Чтобы объединить ячейки, выполните следующие шаги:

1\. Выделите диапазон ячеек, которые нужно объединить

2\. Нажмите кнопку **Merge** на панели инструментов

![Панель инструментов DHTMLX Spreadsheet с кнопкой Merge для объединения диапазона ячеек](/img/merge_cells.png)

или

1\. Выделите диапазон ячеек, которые нужно объединить

2\. Перейдите в меню: *Format -> Merge*

![Меню Format в DHTMLX Spreadsheet с пунктом Merge для объединения ячеек](/img/merge_cells_via_menu.png)

:::info
Объединённая ячейка отображает содержимое верхней левой ячейки выбранного диапазона.
:::

## Разделить ячейки {#split-cells}

Чтобы разделить объединённую ячейку, выполните следующие шаги:

1\. Выделите объединённую ячейку

2\. Нажмите кнопку **Unmerge** на панели инструментов

![Панель инструментов DHTMLX Spreadsheet с кнопкой Unmerge для разделения объединённых ячеек](/img/unmerge_cells.png)

или

1\. Выделите объединённую ячейку

2\. Перейдите в меню: *Format -> Unmerge*

![Меню Format в DHTMLX Spreadsheet с пунктом Unmerge для разделения объединённых ячеек](/img/unmerge_cells_via_menu.png)

## Удаление строк и столбцов с объединёнными ячейками {#removing-rows-and-columns-of-merged-cells}

Если удалить строку или столбец через объединённую ячейку, будут удалены все строки или столбцы, которые охватывает эта ячейка. Это работает так, когда выбрана ячейка или диапазон ячеек, а строка или столбец удаляется через панель инструментов, меню, контекстное меню или методы [`deleteRow()`](api/spreadsheet_deleterow_method.md) / [`deleteColumn()`](api/spreadsheet_deletecolumn_method.md). В контекстном меню название команды показывает весь диапазон, например, *Удалить строки 2-4*.

![Контекстное меню DHTMLX Spreadsheet с подменю «Строки» и командой «Удалить строки 2-4» для объединённой ячейки](/img/remove_merged_rows_context_menu.png)

Если выделены целые строки или столбцы, например, щелчком по их заголовкам или с помощью `Shift + Space` или `Ctrl (Cmd) + Space`, удаляются только выделенные строки или столбцы. Объединённая ячейка, которая их охватывает, становится меньше, а объединённая ячейка, в которой осталась одна ячейка, становится обычной ячейкой.

Объединённые ячейки, расположенные ниже или правее удаляемых строк или столбцов, смещаются вместе с ними.
