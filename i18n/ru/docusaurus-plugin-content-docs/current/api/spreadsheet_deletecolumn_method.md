# deleteColumn()

### Описание {#description}

@short: Удаляет столбец из таблицы

:::info
Метод удаляет столбец, в котором расположена указанная ячейка, и сдвигает столбцы справа от него влево.

Если ячейка находится внутри объединённой ячейки, метод удаляет каждый столбец, который охватывает объединённая ячейка.
:::

### Использование {#usage}

~~~jsx
deleteColumn(cell: string): void;
~~~

### Параметры {#parameters}

- `cell` - (обязательный) идентификатор ячейки, содержащей имя столбца, который следует удалить

### Пример {#example}

~~~jsx {5}
const spreadsheet = new dhx.Spreadsheet("spreadsheet", {});
spreadsheet.parse(data);

// удаляет столбец "G"
spreadsheet.deleteColumn("G2");
~~~

:::note
Можно удалить несколько столбцов, передав диапазон идентификаторов ячеек в качестве параметра метода,  например: "A1:C3". Если диапазон затрагивает объединённую ячейку, удаляются столбцы всей объединённой ячейки. Диапазон, который охватывает столбцы целиком, например, "B1:C100" на листе со 100 строками, удаляется как есть.
:::

### Подробности {#details}

При удалении столбца внутри объединённой ячейки удаляется вся объединённая ячейка со всеми её столбцами:

~~~jsx
spreadsheet.mergeCells("B2:D2");

// removes columns B, C and D
spreadsheet.deleteColumn("C2");
~~~

При удалении столбцов целиком объединённая ячейка, которая их охватывает, уменьшается. Объединённые ячейки справа от удалённых столбцов сдвигаются влево вместе со своими столбцами. Если удалённые столбцы зафиксированы, зафиксированная область уменьшается на количество удалённых зафиксированных столбцов.

События [`beforeAction`](api/spreadsheet_beforeaction_event.md) и [`afterAction`](api/spreadsheet_afteraction_event.md) для действия `"deleteColumn"` получают ячейку, переданную в метод, а не диапазон удалённых столбцов.

**Журнал изменений:** Удаление всех столбцов объединённой ячейки добавлено в v6.0.4
