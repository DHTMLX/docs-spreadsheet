# deleteRow()

### Описание {#description}

@short: Удаляет строку из таблицы

:::info
Метод удаляет строку, в которой расположена указанная ячейка, и сдвигает строки ниже неё вверх.

Если ячейка находится внутри объединённой ячейки, метод удаляет каждую строку, которую охватывает объединённая ячейка.
:::

### Использование {#usage}

~~~jsx
deleteRow(cell: string): void;
~~~

### Параметры {#parameters}

- `cell` - (обязательный) идентификатор ячейки, содержащей идентификатор строки, которую следует удалить

### Пример {#example}

~~~jsx {5}
const spreadsheet = new dhx.Spreadsheet("spreadsheet_container", {});
spreadsheet.parse(data);

// удаляет вторую строку
spreadsheet.deleteRow("G2");
~~~

:::note
Можно удалить несколько строк, передав диапазон идентификаторов ячеек в качестве параметра метода,  например: "A1:C3". Если диапазон затрагивает объединённую ячейку, удаляются строки всей объединённой ячейки. Диапазон, который охватывает строки целиком, например, "A2:Z3" на листе со столбцами от A до Z, удаляется как есть.
:::

### Подробности {#details}

При удалении строки внутри объединённой ячейки удаляется вся объединённая ячейка со всеми её строками:

~~~jsx
spreadsheet.mergeCells("B2:B4");

// removes rows 2, 3 and 4
spreadsheet.deleteRow("B3");
~~~

При удалении строк целиком объединённая ячейка, которая их охватывает, уменьшается. Объединённые ячейки ниже удалённых строк сдвигаются вверх вместе со своими строками. Если удалённые строки зафиксированы, зафиксированная область уменьшается на количество удалённых зафиксированных строк.

События [`beforeAction`](api/spreadsheet_beforeaction_event.md) и [`afterAction`](api/spreadsheet_afteraction_event.md) для действия `"deleteRow"` получают ячейку, переданную в метод, а не диапазон удалённых строк.

**Журнал изменений:** Удаление всех строк объединённой ячейки добавлено в v6.0.4
