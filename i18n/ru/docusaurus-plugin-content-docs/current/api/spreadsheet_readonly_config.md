# readonly

### Описание {#description}

@short: Необязательный. Включает/отключает режим только для чтения

### Использование {#usage}

~~~jsx
readonly?: boolean;
~~~

### Конфигурация по умолчанию {#default-config}

~~~jsx
readonly: false
~~~

### Пример {#example}

~~~jsx {2}
const spreadsheet = new dhx.Spreadsheet("spreadsheet_container", {
  readonly: true,
  // other config parameters
});
~~~

### Подробности {#details}

В режиме только для чтения панель инструментов, меню и строка формул скрыты, а контекстное меню и значок меню столбца недоступны. Вкладки листов остаются, но без кнопки добавления листа, контекстного меню листа и переименования двойным щелчком.

Пользователи по-прежнему могут просматривать и копировать данные:

- ячейка A1 активна после загрузки данных
- по ячейкам можно перемещаться с помощью клавиатуры и выделять их мышью, при этом срабатывают события выделения
- ячейки можно копировать с помощью `Ctrl (Cmd) + C` и искать с помощью `Ctrl (Cmd) + F`
- листы можно переключать на вкладках листов и с помощью клавиатуры
- ссылки в ячейках можно открывать, но кнопки редактирования и удаления ссылки в окне ссылки отключены

Изменения данных отклоняются:

- ввод текста, клавиши редактирования, вырезание и вставка, отмена и повтор действий, а также сочетания клавиш, которые форматируют ячейки, вставляют ссылку, добавляют лист или показывают скрытые строки и столбцы, игнорируются, а программы чтения с экрана сообщают "The sheet is read-only"
- методы, которые изменяют данные, например, [`setValue()`](api/spreadsheet_setvalue_method.md), [`setStyle()`](api/spreadsheet_setstyle_method.md) и [`deleteRow()`](api/spreadsheet_deleterow_method.md), а также метод [`startEdit()`](api/spreadsheet_startedit_method.md) игнорируются. Методы [`parse()`](api/spreadsheet_parse_method.md) и [`load()`](api/spreadsheet_load_method.md) по-прежнему загружают данные
- маркер заполнения скрыт
- размер столбцов и строк нельзя изменить перетаскиванием их границ, а двойной щелчок по границе столбца не подгоняет ширину столбца под данные

Чтобы отключить также навигацию с помощью клавиатуры и выделение, установите для параметра [`selection`](api/spreadsheet_selection_config.md) значение `false`. В этом случае в Spreadsheet нет активной ячейки, а ячейки нельзя выделить мышью, с помощью клавиатуры или API:

~~~jsx {3}
const spreadsheet = new dhx.Spreadsheet("spreadsheet_container", {
  readonly: true,
  selection: false,
  // other config parameters
});
~~~

**Журнал изменений:** Навигация с помощью клавиатуры, выделение, копирование и поиск в режиме только для чтения добавлены в v6.0.4
