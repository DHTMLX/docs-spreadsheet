# 접근성 적합성 보고서

이 보고서는 DHTMLX Spreadsheet가 주요 접근성 표준을 어떻게 준수하는지 설명합니다. 보고서는 **VPAT® 2.5 (International Edition)** 구조를 따릅니다. 접근성 기능과 구성 방법에 대한 작업 중심 개요는 [접근성](accessibility.md) 가이드를 참조하십시오.

**제품명/버전:** DHTMLX Spreadsheet v6.0.4

**보고서 날짜:** 2026년 10월

**제품 설명:** DHTMLX Spreadsheet는 웹 애플리케이션용 JavaScript 스프레드시트 컴포넌트입니다. 인터페이스는 메뉴 바, 툴바, 수식 입력줄, 행 및 열 머리글이 있는 셀 그리드, 시트 탭으로 구성됩니다. 수식, 셀 서식, 셀 병합, 행 및 열 고정, 정렬, 필터링, 검색, 데이터 유효성 검사, 셀 링크, Excel 가져오기 및 내보내기 기능을 제공합니다. 이 컴포넌트는 호스트 웹 애플리케이션에 포함되어 사용됩니다.

**연락처:** [info@dhtmlx.com](mailto:info@dhtmlx.com)

## 참고 사항 {#notes}

- 이 보고서는 DHTMLX Spreadsheet를 **권장 접근성 구성**으로 평가합니다. 권장 구성은 WAI-ARIA 출력과 키보드 탐색이 항상 켜져 있는 기본 구성이며, `dhx.setTheme()` 또는 `data-dhx-theme` 속성으로 `contrast-light` 또는 `contrast-dark` 테마를 설정한 상태입니다. 적합성 수준이 이 구성에 의존하는 경우 비고에 명시합니다. 설정 방법은 [접근성](accessibility.md) 가이드를 참조하십시오.
- DHTMLX Spreadsheet는 호스트 애플리케이션이 렌더링하는 **웹 콘텐츠**입니다. 페이지 수준의 책임 사항(페이지 제목, `<html lang>`, 건너뛰기/우회 메커니즘, 사이트 전체 탐색)은 호스트 애플리케이션에 속하며, 설명과 함께 *해당 없음*으로 보고합니다.
- WCAG 표에서는 **Web** 응답만 작성합니다. *Electronic Docs*, *Software*, *Closed*, *Authoring Tool* 행은 *해당 없음*입니다. 이 제품은 독립 실행형(비웹) 소프트웨어, 폐쇄형 기능, 저작 도구, 전자 문서가 아니기 때문입니다.
- 작성자가 셀 스타일을 통해 셀에 적용하는 색상은 문서 데이터의 일부이며 제품 평가 대상에 포함되지 않습니다.

**사용한 평가 방법:**

- 자동 테스트: 검색 바, 목록 편집기, 대화 상자, 알림이 열린 상태에서 `light`, `dark`, `contrast-light`, `contrast-dark` 테마로 axe-core를 실행했습니다.
- 컴포넌트 소스와 스타일시트의 수동 코드 검토: 위젯 각 부분의 role과 ARIA 속성, 키보드 핸들러와 포커스 영역, 접근 가능한 이름과 해당 로캘 키, 테마 색상 토큰을 검토했으며 네 가지 테마에 대해 명암비를 계산했습니다.
- 보조 기술 테스트: Windows에서 **NVDA + Firefox** 및 **JAWS + Chrome**, macOS에서 **VoiceOver + Safari**로 수동 점검을 수행했습니다.
- 브라우저 재정의: 200% / 400% 확대, 320 CSS px에서의 리플로우, WCAG 텍스트 간격 재정의.

## 용어 {#terms}

- **지원함(Supports):** 제품의 기능에 알려진 결함 없이 기준을 충족하는 방법이 하나 이상 있거나, 동등한 촉진(equivalent facilitation)으로 충족합니다.
- **부분 지원(Partially Supports):** 제품의 일부 기능이 기준을 충족하지 않습니다.
- **지원하지 않음(Does Not Support):** 제품 기능의 대부분이 기준을 충족하지 않습니다.
- **해당 없음(Not Applicable):** 해당 기준이 제품과 관련이 없습니다.

## WCAG 2.x 보고서 {#wcag-2x-report}

DHTMLX Spreadsheet는 웹 콘텐츠이므로 아래에는 **Web** 응답만 작성합니다. "AA 적합 테마 필요"는 구성 의존성이며 결함이
아닙니다. 기준 4.1.1 구문 분석(Parsing)은 WCAG 2.2에서 제거되어 보고하지 않습니다.

### 표 1: 성공 기준, Level A {#table-1-success-criteria-level-a}

| 기준 | 적합성 수준 | 비고 및 설명 |
|---|---|---|
| **1.1.1** 텍스트 아닌 콘텐츠 | 지원함 | 아이콘은 글꼴 글리프입니다. 아이콘만 있는 컨트롤은 로캘 또는 툴팁에서 접근 가능한 이름을 가져옵니다(예: "Add sheet", "Close search", "Select all"). 색상 버튼은 색상 이름을 가집니다(예: "Text color: dark gray"). 장식용 아이콘(잠금, 필터, 열 메뉴, 숨겨진 줄 표시), 선택 레이어, 병합된 셀에 가려진 셀은 `aria-hidden="true"`로 숨깁니다. 이들이 나타내는 상태는 셀 안의 텍스트("locked", "Filter applied" 등)로 전달됩니다. |
| **1.2.1** 오디오 전용 및 비디오 전용(녹화) | 해당 없음 | 제품에 오디오 또는 비디오 콘텐츠가 없습니다. |
| **1.2.2** 자막(녹화) | 해당 없음 | 녹화된 멀티미디어가 없습니다. |
| **1.2.3** 오디오 설명 또는 미디어 대체물(녹화) | 해당 없음 | 녹화된 멀티미디어가 없습니다. |
| **1.3.1** 정보와 관계 | 지원함 | 셀은 `row`, `columnheader`, `rowheader`, `gridcell` role을 가진 "Spreadsheet"라는 이름의 `grid`입니다. 위치는 `aria-rowcount`/`aria-colcount`에 대한 `aria-rowindex`/`aria-colindex`로, 병합된 셀의 범위는 `aria-colspan`/`aria-rowspan`으로, 편집 가능 여부는 `aria-readonly`로, 선택은 `aria-selected`와 `aria-multiselectable`로 노출됩니다. 툴바, 메뉴 바, 시트 탭은 이름이 있는 `toolbar` 및 `menubar` 요소입니다. 서식 토글은 툴바에서 `aria-pressed`를 가지며 메뉴 바에서는 `menuitemcheckbox`이고, 상호 배타적인 서식 옵션은 `aria-checked`를 가진 `menuitemradio`입니다. |
| **1.3.2** 의미 있는 순서 | 지원함 | DOM 및 읽기 순서는 시각적 순서(메뉴 바, 툴바, 수식 입력줄, 셀, 시트 탭)를 따릅니다. 셀은 `aria-rowindex`/`aria-colindex`로 시트 내 위치를 전달하므로, 행과 열이 스크롤되어 DOM에서 사라져도 순서가 유지됩니다. |
| **1.3.3** 감각적 특성 | 지원함 | 어떤 지침이나 레이블도 모양, 크기, 공간적 위치에만 의존하지 않으며, 상호작용 요소는 텍스트 또는 ARIA 이름을 가집니다. |
| **1.4.1** 색의 사용 | 지원함 | 색상으로 나타내는 각 상태에는 테두리, 채우기, 표시 또는 텍스트도 함께 제공됩니다. 활성 셀, 선택한 범위, 검색 일치 항목, 복사한 범위, 잘못된 셀이 해당하며, `aria-selected` 또는 셀 안의 텍스트가 함께 제공됩니다. 필터로 숨겨진 행은 행 번호에 간격을 남깁니다. 색상 버튼은 접근 가능한 이름에 색상 이름을 포함합니다. |
| **1.4.2** 오디오 제어 | 해당 없음 | 제품은 자동 재생 오디오를 생성하지 않습니다. |
| **2.1.1** 키보드 | 지원함 | 셀에 대한 모든 명령에 키가 있으며 [단축키 목록](hotkeys.md)에 나열되어 있습니다. `Shift`+`F10` 또는 Menu 키로 컨텍스트 메뉴를 엽니다. `Ctrl`+`F6`은 메뉴, 툴바, 시트, 시트 탭 사이로 포커스를 이동합니다. 바, 바의 드롭다운과 팝업, 목록 편집기는 화살표 키, `Home`, `End`, `Enter`, `Esc`로 작동합니다. 열 너비, 행 높이, 열 필터에는 컨텍스트 메뉴 명령이 있습니다. |
| **2.1.2** 키보드 트랩 없음 | 지원함 | 시트의 마지막 셀에서 `Tab`, 첫 번째 셀에서 `Shift`+`Tab`을 누르면 포커스가 셀에서 페이지의 다음 또는 이전 부분으로 이동하며, `Ctrl`+`F6`은 Spreadsheet의 각 부분 사이로 포커스를 이동합니다. 목록 편집기에서 `Tab`은 편집을 종료하고 `Esc`는 취소하며, 화살표 키를 사용한 후에도 동일합니다. `Esc`와 `Tab`은 툴바 팝업을 닫고 포커스를 해당 버튼으로 되돌립니다. |
| **2.1.4** 문자 키 단축키 | 지원함 | 모든 단축키는 수정자 키(`Ctrl`, `Alt`, `Shift`) 또는 비문자 키(`F2`, `F6`, `F10`, `F11`, `Enter`, `Esc`, `Delete`, 화살표)를 사용합니다. 셀에서 문자를 입력하면 셀에 입력되며, 이는 셀의 본래 목적이고 명령을 실행하지 않습니다. |
| **2.2.1** 시간 조절 가능 | 해당 없음 | 제품은 시간 제한을 설정하지 않습니다. |
| **2.2.2** 일시정지, 정지, 숨기기 | 지원함 | 자동으로 갱신되거나 움직이거나 깜박이거나 스크롤되는 콘텐츠가 없습니다. 5초를 넘는 애니메이션이 없습니다. |
| **2.3.1** 세 번 깜박임 또는 임계값 이하 | 지원함 | 제품에 깜박이는 콘텐츠가 없습니다. |
| **2.4.1** 블록 건너뛰기 | 해당 없음 | 페이지 수준에 적용되며, 우회 메커니즘은 호스트 애플리케이션에 속합니다. |
| **2.4.2** 페이지 제목 | 해당 없음 | 페이지 제목은 호스트 애플리케이션의 책임입니다. |
| **2.4.3** 초점 순서 | 지원함 | 셀은 활성 셀에 하나의 탭 정지 지점을 가지며, 툴바, 메뉴 바, 시트 탭은 각각 하나의 탭 정지 지점을 가지고 시각적 순서를 따릅니다. `Tab`은 마지막 셀과 첫 번째 셀에서 시트를 벗어납니다. 대화 상자는 포커스를 가져가고 `Tab`을 내부에 유지하며, 닫힐 때 포커스를 활성 셀로 되돌립니다. 메뉴, 컨텍스트 메뉴, 팝업은 포커스를 연 컨트롤로 되돌리며, 텍스트 또는 배경 색상을 적용한 후에는 포커스가 활성 셀로 돌아갑니다. 활성 셀은 포커스를 받을 때 보이는 위치로 스크롤됩니다. |
| **2.4.4** 링크 목적(문맥 내) | 지원함 | 셀의 링크는 작성자가 설정한 링크 텍스트 또는 주소를 텍스트로 가진 `<a href>` 요소로 렌더링됩니다. 셀이 선택되면 셀 텍스트에 "link"가 추가되며, `Alt`+`Enter`로 링크를 엽니다. |
| **2.5.1** 포인터 제스처 | 지원함 | 다중 포인트 또는 경로 기반 제스처가 필요한 작업이 없으며, 모든 드래그 작업에는 드래그가 아닌 대안이 있습니다(2.5.7 참조). |
| **2.5.2** 포인터 취소 | 지원함 | 열 및 행 크기 조절과 채우기 핸들은 놓을 때 적용되며, 한 번의 실행 취소로 각각을 되돌릴 수 있습니다. 툴바, 메뉴, 시트 탭의 명령은 `click` 시 실행됩니다. |
| **2.5.3** 이름에 레이블 포함 | 지원함 | 보이는 텍스트가 있는 컨트롤은 그 텍스트를 접근 가능한 이름으로 사용합니다. 메뉴 항목, 컨텍스트 메뉴 명령, 시트 탭, 대화 상자 버튼이 해당합니다. 아이콘 버튼은 툴팁으로, 색상 버튼은 툴팁 뒤에 색상 이름을 붙여 이름을 지정합니다. |
| **2.5.4** 동작 작동 | 해당 없음 | 기기 동작이나 사용자 동작으로 작동하는 기능이 없습니다. |
| **3.1.1** 페이지의 언어 | 해당 없음 | 문서 언어(`<html lang>`)는 호스트 애플리케이션이 설정합니다. |
| **3.2.1** 초점 시 | 지원함 | 포커스를 받아도 문맥이 바뀌지 않습니다. 열 문자, 행 번호 또는 모서리를 클릭하면 해당 줄이 선택되고 포커스는 활성 셀에 유지됩니다. |
| **3.2.2** 입력 시 | 지원함 | 값을 변경해도 문맥이 바뀌지 않습니다. 셀 편집, 목록에서 값 선택, 검색 바에 입력하면 시트가 그 자리에서 갱신되며, 이는 해당 컨트롤의 문서화된 목적입니다. |
| **3.2.6** 일관된 도움말 (2.2 전용) | 해당 없음 | 위젯은 도움말 메커니즘을 제공하지 않으며, 이는 페이지 수준의 사항입니다. |
| **3.3.1** 오류 식별 | 지원함 | 수식 오류와 잘못된 목록 값은 셀 내용에 설명됩니다(예: "Reference error. Check the cell references", "Invalid value. Choose a value from the list"). 편집으로 발생한 새 수식 오류와 잘못된 값은 라이브 영역을 통해 안내되며, 잘못된 값의 편집기에는 `aria-invalid="true"`가 설정됩니다. |
| **3.3.2** 레이블 또는 지침 | 지원함 | 셀 편집기는 "Cell editor, B7", 수식 입력줄은 "Formula bar, B7"로 이름이 지정되며, 편집 중인 셀의 주소를 포함합니다. 대화 상자 필드에는 레이블이 있으며(예: "Width in pixels"), 검색 바 버튼은 "Previous match", "Next match", "Close search"로 이름이 지정됩니다. |
| **3.3.7** 중복 입력 (2.2 전용) | 지원함 | 제품에는 이미 입력한 정보를 다시 요구하는 다단계 프로세스가 없습니다. |

### Clause 5: 일반 요구 사항 {#clause-5-generic-requirements}

**대부분 해당 없음.** Clause 5는 폐쇄형 기능과 하드웨어 유형의 요구 사항을 다룹니다. DHTMLX
Spreadsheet는 플랫폼 및 브라우저 보조 기술과 함께 작동하는 개방형 웹 소프트웨어이므로, 폐쇄형 기능 하위 조항, 생체 인식(5.3), 조작 가능한 부분(5.5),
잠금/토글 컨트롤 상태(5.6)는 해당 없음입니다. 일반 요구 사항이 일반적인 보조 기술 지원으로 충족되는 경우에는
Clause 9(Web)와 WCAG 결과에서 다룹니다.

### Clause 9: 웹 {#clause-9-web}

**WCAG 2.x 섹션을 참조하십시오.** Clause 9.1.1.1-9.4.1.3은 위의 표 1과 표 2에 있는 WCAG 2.2 Level A/AA
결과에 대응합니다.

### Clause 11: 소프트웨어 {#clause-11-software}

**해당 없음 (Clause 9에서 평가).** DHTMLX Spreadsheet는 Clause 9(Web)에서 평가하는 웹 콘텐츠이며,
비웹 소프트웨어가 아닙니다. WCAG에 대응하는 소프트웨어 조항(11.1.1.1-11.4.1.3)은 WCAG
2.x 결과에서 다룹니다. 11.8(저작 도구)은 제품이 저작 도구가 아니므로 해당 없음입니다.
